# Alura-Store

En un entorno empresarial cada vez más competitivo, la toma de decisiones estratégicas debe estar respaldada por información objetiva y análisis rigurosos. 
En este contexto, se ha llevado a cabo un análisis de datos detallado sobre el desempeño de cuatro tiendas pertenecientes a una misma organización. 
El propósito principal de este estudio es identificar, con base en métricas clave como ventas, costos operativos, rentabilidad, calificación y otros indicadores relevantes,
cuál de estas tiendas presenta el menor desempeño y, por tanto, debería considerarse para su venta. Esta decisión no solo busca optimizar los recursos de la empresa, 
sino también fortalecer su estructura financiera y operativa, enfocando esfuerzos en las unidades más rentables y con mayor potencial de crecimiento.
